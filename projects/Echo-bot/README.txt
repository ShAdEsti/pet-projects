Echo Bot на aiogram 3.26.0
=====================================

Демонстрационный Telegram-бот с удобным интерфейсом. Проект создан для портфолио.

Возможности:
-------------------------------------
• Удобная клавиатура с кнопками внизу
• Inline-кнопки под сообщениями
• Реакции на популярные фразы
• Эхо-режим (повторяет сообщения)
• Команды: /start, /help, /info
• Чистый и хорошо документированный код

Технологии:
-------------------------------------
• Python 3.10+
• aiogram 3.26.0
• ReplyKeyboard + InlineKeyboard

Как запустить:
-------------------------------------
1. Установи зависимости:
   pip install aiogram

2. Вставь свой токен в файл BOT_Portfolio.py

3. Запусти бота:
   python BOT_Portfolio.py
